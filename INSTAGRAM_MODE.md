# Instagram-Style Marketplace - Новые возможности

## 🎉 AiGram теперь полноценный Instagram маркетплейс!

### Что нового?

#### 🔥 Instagram-стиль интерфейс
- **Лента постов** - товары отображаются как посты в Instagram
- **Двойной тап** для лайка товаров
- **Stories** - истории с товарными предложениями
- **Профиль** - страница продавца с подписчиками
- **Навигация** - Instagram-стиль bottom navigation
- **Модальные окна** - детали товара в стиле Instagram

#### 🤖 AI работает в реальном времени!

**ВАЖНО:** AI больше не работает в демо-режиме!

Теперь для работы AI необходим настоящий API ключ от Google Gemini.

### Как настроить AI (обязательно!)

1. **Получите API ключ:**
   - Перейдите на https://makersuite.google.com/app/apikey
   - Войдите с вашим Google аккаунтом
   - Создайте новый API ключ

2. **Добавьте ключ в проект:**
   ```bash
   # Создайте файл .env в корне проекта
   echo "VITE_GEMINI_API_KEY=ваш_ключ_здесь" > .env
   ```

3. **Перезапустите сервер:**
   ```bash
   npm run dev
   ```

### Без API ключа:
- ❌ AI чат не будет работать
- ❌ Вы увидите сообщение об ошибке: "AI не настроен. Пожалуйста, добавьте VITE_GEMINI_API_KEY"
- ✅ Все остальные функции (покупки, лайки, корзина) работают нормально

## Установка и запуск

```bash
# 1. Установите зависимости
npm install

# 2. Создайте .env файл
cp .env.example .env

# 3. Добавьте ваш API ключ в .env
nano .env  # или используйте любой редактор

# 4. Запустите проект
npm run dev

# 5. Откройте в браузере
```

## Troubleshooting

### AI не работает
```
❌ Ошибка: "AI не настроен"
✅ Решение: Добавьте VITE_GEMINI_API_KEY в .env файл
```

### Лента не загружается
```
✅ Проверьте интернет соединение
✅ Обновите страницу (Ctrl+R)
```

### Нет кнопки "Купить"
```
✅ Убедитесь, что вы в Instagram Mode
✅ Кнопка внизу каждого поста
```
