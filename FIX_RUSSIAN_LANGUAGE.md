# Исправление: Русский язык по умолчанию

## Проблема
Пользователь сообщил: **"Общайся сомной на руски not found говорит"**

Это означало, что при попытке общаться на русском языке появлялась ошибка "not found" (не найдено).

## Причина
Язык по умолчанию в приложении был установлен на **'tj' (таджикский)** вместо **'ru' (русский)**.

## Что было исправлено

### 1. Язык интерфейса по умолчанию
**Файл:** `App.tsx`
- **Было:** `const [language, setLanguage] = useState<Language>('tj');`
- **Стало:** `const [language, setLanguage] = useState<Language>('ru');`

Теперь при открытии приложения интерфейс отображается на **русском языке**.

### 2. Брендинг AI-помощника
**Файл:** `services/geminiService.ts`
- **Было:** `консультант магазина "Мир Техники"`
- **Стало:** `консультант магазина "AiGram"`

AI-помощник Zud AI теперь представляется как консультант магазина **AiGram**.

### 3. Техническое исправление
**Файл:** `tsconfig.json`
- Удалена зависимость от `"types": ["vite/client"]` для корректной сборки проекта

## Результат

✅ **Приложение теперь работает на русском языке по умолчанию**
